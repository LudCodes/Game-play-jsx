# Prompts utilizados no desenvolvimento do projeto GamePlay

---

**Prompt:**
> "Estou desenvolvendo um app em React Native com Expo (usando expo-router) e quero revisar alguns conceitos antes de continuar o projeto. Pode me ajudar com os seguintes pontos?

> Componentes básicos: qual a diferença entre View, Text e ScrollView, e quando usar cada um?
> Navegação: como funciona a navegação com expo-router, e qual a diferença entre router.push e router.replace?
> Flexbox: explica como funcionam flexDirection, justifyContent, alignItems e gap, com exemplos práticos de layout (por exemplo, alinhar um ícone e um texto lado a lado, ou centralizar um título dentro de um cabeçalho).
> Grid: como simular um layout tipo grid (cards lado a lado, quebrando linha) usando flexbox, já que o React Native não tem CSS Grid nativo?
> Boas práticas de estilo: qual a diferença entre usar StyleSheet.create e passar um objeto de estilo direto na prop style, e por que uma abordagem é preferível?

> Pode explicar cada ponto com exemplos curtos de código, baseado no protótiopo enviado?"
